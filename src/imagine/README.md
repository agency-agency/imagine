# Imagine behavior

Imagine composes the public Manganese window reducer and Stage with its own
split-first policy, zero-gap placement, rounded chrome, optional hidden chrome,
workspace rail, Finder, media controls and native quick settings.

Host configuration supplies display preferences, font and application commands.
All workspaces remain usable on one display. Output identities and personal
workspace assignments are not shared package defaults.

The existing shell command owner dispatches optional snapshot, onboarding,
chat and presentation commands. Read-only snapshot transport does not grant
mutating window authority. Keyboard, lock and modal state take precedence over
delayed application focus.

A shell update ships its entire checked import graph together. A Domicile
engine update additionally requires the normal physical session transition;
installation on disk does not alter an already loaded engine.

See the root README, CONTRIBUTING.md and provenance/source.json for packaging,
compatibility and source history.
